# ExamPractice

A C# console application for registering and managing undergraduate and postgraduate student records. This project was created for PRG261 exam practice.

## Features

- Register undergraduate and postgraduate students
- Display all registered students
- Search for a student by ID
- Remove a student by ID

## Requirements

- Windows with Visual Studio (or MSBuild)
- .NET Framework 4.7.2 Developer Pack

## Run

1. Open `ExamPractice.slnx` in Visual Studio.
2. Build the solution.
3. Run the `ExamPractice` project.

Student records are held in memory, so they are cleared when the application exits.
